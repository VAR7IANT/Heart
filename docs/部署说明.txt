心动引力 · 独立部署包

这是纯静态网站，无需 Node.js、数据库、构建命令或额外音频文件。
页面不显示文字和按钮，保留立体爱心、星尘、流星、点击绽放。

使用方式
1. 首次点击或轻触页面，开启心跳声，并触发粒子绽放。
2. 也可以按空格或 Enter 开启声音；按 M 切换静音。
3. 心跳声音与爱心双拍动画共用音频输出时钟，避免长期漂移。
4. 切换到后台时，动画和声音暂停；返回时恢复。部分浏览器可能需要再次点击以恢复声音。
5. 尊重系统“减少动态效果”设置；启用该设置时画面静止，心跳声也不播放。

部署文件
把 index.html、style.css、app.js、heartbeat.js 放在同一个网站根目录。
这四个文件就是完整网站，无外部字体、CDN 或音频文件依赖。
本地可双击 index.html 查看；线上使用 HTTP/HTTPS 静态托管。

使用现有 VPS
1. 把四个文件上传到站点目录，例如 /var/www/heart。
2. 在 Nginx 或网站面板中新增静态站点，填写你的域名和上述目录。
3. 将域名的 A/AAAA 记录指向实际服务器，按托管方要求配置 DNS。
4. 为该域名配置 HTTPS。docs/nginx.conf.example 提供 HTTP 基础配置示例。

使用静态托管平台
上传四个文件；如果平台要求构建输出目录，选择包含 index.html 的目录。
随后在平台绑定自己的域名，并使用平台实际返回的 DNS 记录完成解析。
也可以继续使用当前 Sites 托管并绑定自己的域名；需要先提供具体域名。
